# YOMI

**YOMI for Nintendo Switch — Official Release Repository**

这里是 YOMI 的官方发行仓库。

本仓库只用于发布已经编译完成的 Nintendo Switch Homebrew 程序，不公开主开发仓库源码。

## 下载

请前往本仓库的 **Releases** 页面下载最新版本的 `YOMI-<version>.nro`。

## 安装

1. 下载最新版本 NRO。
2. 放入 SD 卡：`/switch/YOMI/YOMI.nro`
3. 从 Homebrew Menu 启动 YOMI。

## 更新清单

- `version.json`：当前 Stable
- `versions.json`：Stable 历史版本
- `beta.json`：Beta 测试版本

YOMI 为非官方 Nintendo Switch Homebrew 项目，与 Nintendo 无隶属、授权或合作关系。
